# 常见故障模式

问题重复出现、首次修复没生效，或症状更像运行时状态、入口和环境差异时，对照下面的信号。命中只说明值得先查，仍要用证据确认。

部分条目改编自 [tw93/Waza](https://github.com/tw93/Waza) 的 `hunt` 技能（MIT）。

## 入口与环境

| 模式 | 信号 | 先查 |
|---|---|---|
| 改错了副本 | 改了代码但界面或输出不变；同一功能有多份实现 | 从实际渲染或执行的实例反向追踪，确认改的是被调用的那份 |
| 入口不同 | 从应用内打开正常，通过文件关联、拖放、深链、代理或冷启动打开就坏 | 按用户描述的入口复现；冷启动时状态可能还没准备好 |
| 安装物与源码不一致 | 源码目录运行正常，安装后的命令、包装脚本或 PATH 中的版本行为旧 | 检查安装包内容、shebang、可执行位、包装目标和 PATH 顺序，通过临时前缀安装复现 |
| 能力受限的运行面 | 在模拟器、沙箱或缺少权限的环境中修某个能力相关的问题 | 先确认运行面本身支持该能力；不支持时说明并停止 |
| 本地通过 CI 失败 | 同一测试只在 CI 失败 | 先对齐运行时版本、环境变量、时区和 locale，再查代码 |
| 只对报告人生效的修复 | 修复匹配报告人的配置，默认路径不变或退化 | 说明修复影响的是默认体验还是特定配置，优先修默认路径 |

## 状态与数据

| 模式 | 信号 | 先查 |
|---|---|---|
| 持久化旧数据 | 算法改了，输出仍是旧结果 | 运行时是否在读旧代码写入的缓存、快照或扫描结果；同一修改中失效或升级版本 |
| 生成物边界 | 源码改了，产物、包、校验和仍是旧行为 | 源码到产物的生成规则、构建是否监听该路径，直接检查产物内容 |
| 队列或数据库边界 | 界面显示运行中，但没有 worker 处理；重试只修好单条 | 追踪请求、入队、领取、持久化、刷新整条链路，直接查队列行或任务状态 |
| 切换后状态未重算 | 切换主题、模式或语言后出错，重启后正常 | 追踪切换路径上的重算或失效逻辑，不逐像素调样式 |
| 守卫生命周期 | 权限或状态守卫本地正常，延迟回调、重启或其他入口绕过它 | 追踪守卫的创建、保留、失效和所有入口；需要跨重启时用持久状态 |
| 预览与执行范围不一致 | dry-run、计数或预览与实际修改的集合不同 | 让展示、预演和执行使用同一个判定来源，测试中比对计划集合与执行输入 |

## 进程与 I/O

| 模式 | 信号 | 先查 |
|---|---|---|
| 交互输入挂起 | CI 卡住、进度不结束、非交互模式出现认证提示 | 分别在重定向 stdin、TTY 和非 TTY 下复现 |
| 管道背压 | 子进程只在大输出时挂起，小夹具通过 | 父进程是否等退出才读 stdout/stderr；用超过管道缓冲的输出测试 |
| 中断被当成功 | 取消、超时、SIGINT 后报告成功，临时文件或锁让重试误以为已完成 | 区分中断、成功和预期失败；检查中断后的清理、锁释放和重试幂等 |
| 输出契约回归 | 自动化在日志、进度、JSON 结构或退出码变化后失效 | 分别断言退出码、stdout 和 stderr；机器可读模式不混入人类日志 |
| locale 相关输出 | 数值对作者正确、对部分用户为零或错 | 解析子进程输出时在启动边界固定 `LC_ALL=C`，不逐个修解析器 |
| 严格解码吞掉整段输出 | 某些用户上解析结果整体为空；有非 ASCII 设备名或文件名 | 查找无容错的 UTF-8 解码；报告类数据宽松解码，签名校验保持严格 |
| 临时文件冲突 | 并发运行互相覆盖、清理删错文件、读到半写文件 | 用唯一临时目录或原子 rename，清理只限本次创建的文件 |

## 判定逻辑

| 模式 | 信号 | 先查 |
|---|---|---|
| 单一探针判定存在性 | “已安装、运行中、已注册”判断对部分用户错误，并驱动删除或禁用 | 列出对象所有合法存在方式；区分探针超时和不存在；破坏性分支要求第二来源确认 |
| 无权限读取返回看似合理的值 | 指标对自己的进程或文件正确，对其他用户或 root 拥有的为零或过期 | 分别统计有权限和无权限对象的成功数；回退值的含义要与主来源一致 |
| 恢复逻辑依赖它要恢复的东西 | 修复、重装或自愈每次都走到同一死路 | 恢复路径的前置条件在故障状态下是否成立；检查命令中的绝对路径真实存在；断言最终状态而不是命令形状 |
| 看门狗只按快路径调 | 慢网络、冷缓存、大负载下被判失败，每次在相同耗时失败 | 每个超时都对照最慢的健康场景；用真实存活信号替代“N 秒无输出” |
| 用展示字符串比较 | 永远提示有更新、永远显示已变化、永远不匹配 | 比较版本号、哈希或 ID 等机器标识，只有缺失时才回退到展示文本；所有重复比较的位置一起修 |
| 聚合键有变体 | 计数或分类少了一部分，缺失项有共同前缀或后缀 | 列出写入该类键的所有位置和真实变体，用前缀、正则或显式列表匹配 |
| 拒绝条件不止一个 | 修好可复现的那个原因后，同一守卫因其他原因继续拦住下一位用户 | 枚举守卫所有拒绝分支，每个给出可区分的代码、原因和下一步命令 |
